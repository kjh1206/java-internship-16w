## 题目一：存在重复元素（LeetCode 217，简单）

**题目**：给你一个整数数组 `nums`。如果任一值在数组中出现**至少两次**，返回 `true`；如果数组中每个元素互不相同，返回 `false`。

**示例**

```
输入：nums = [1,2,3,1]
输出：true

输入：nums = [1,2,3,4]
输出：false

输入：nums = [1,1,1,3,3,4,3,2,4,2]
输出：true
```

**题眼**

<details>
<summary>点开看思路</summary>

三种写法，重点体会复杂度：

1. **排序后相邻比较**：O(n log n)，O(1) 额外空间（如果允许改原数组）
2. **HashSet**：边遍历边 `add`，`add` 返回 false 就说明重复了 → O(n)，O(n) 空间
3. **暴力双重循环**：O(n²)，会超时，只用来对照

`Set.add` 返回值这个用法要记住：**添加成功返回 true，已存在返回 false**。

</details>

**要求**：写 HashSet 版 + 排序版，各测三组。

## 题目二：最长连续序列（LeetCode 128，中等）

**题目**：给定一个未排序的整数数组 `nums`，找出数字连续的最长序列（不要求序列元素在原数组中连续）的长度。

**要求**：设计并实现时间复杂度为 **O(n)** 的算法。

**示例**

```
输入：nums = [100,4,200,1,3,2]
输出：4
解释：最长数字连续序列是 [1, 2, 3, 4]，长度为 4。

输入：nums = [0,3,7,2,5,8,4,6,0,1]
输出：9
```

**题眼**

<details>
<summary>点开看思路（建议先自己想 20 分钟）</summary>

**朴素想法**：排序后扫一遍，O(n log n)。但题目要 O(n)。

**关键观察**：只从"连续段的起点"开始数。什么是起点？`x` 是起点，当且仅当 `x - 1` 不在集合里。

```java
Set<Integer> set = new HashSet<>();
for (int x : nums) set.add(x);

int best = 0;
for (int x : set) {
    if (set.contains(x - 1)) continue;   // 不是起点，跳过
    int y = x, len = 1;
    while (set.contains(y + 1)) { y++; len++; }
    best = Math.max(best, len);
}
```

**为什么是 O(n)**：内层 `while` 看起来嵌套，但每个数只会被"从起点往后数"访问一次——因为只有起点会进入 while，而一段连续序列只有一个起点。所以总步数 ≤ n。

这是"**看似两层循环实则 O(n)**"的经典例子，和第 6 周滑动窗口那个题一个套路。

**坑**：必须遍历 `set` 而不是 `nums`，否则重复元素会让你重复计数。

</details>

**要求**：先写排序版（保证能过），再写 O(n) 版；测 `[100,4,200,1,3,2]` → 4、`[0,3,7,2,5,8,4,6,0,1]` → 9、`[]` → 0、`[1]` → 1。
