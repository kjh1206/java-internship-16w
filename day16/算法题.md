## 题目一：两个数组的交集（LeetCode 349，简单）

**题目**：给定两个数组 `nums1` 和 `nums2`，返回它们的**交集**。输出结果中的每个元素一定是**唯一**的。我们可以**不考虑输出结果的顺序**。

**示例**

```
输入：nums1 = [1,2,2,1], nums2 = [2,2]
输出：[2]

输入：nums1 = [4,9,5], nums2 = [9,4,9,8,4]
输出：[9,4]（顺序任意，[4,9] 也对）
```

**题眼**：

- 用 `HashSet` 存 `nums1`（自动去重），再遍历 `nums2`，命中就放进结果集（`LinkedHashSet` 可保顺序，`HashSet` 也行）。
- 复杂度 O(n+m)。暴力双循环 O(n×m) 在 10 万数据下必然超时。

**坑**：

- 结果要**去重**（用 Set 存结果，不要用 List）
- 不要假设数组有序
- 进阶（LC 350 是变体）：如果要求"出现次数取较小者"，改用 `HashMap<值, 次数>` 计数，不能用 Set

**复杂度**：时间 O(n+m)，空间 O(n)。

**验收**

- [ ] `[1,2,2,1]` / `[2,2]` → `[2]`
- [ ] `[4,9,5]` / `[9,4,9,8,4]` → `[9,4]` 或 `[4,9]`
- [ ] `[1,2,3]` / `[4,5,6]` → `[]`
- [ ] `[]` / `[1]` → `[]`

## 题目二：字母异位词分组（LeetCode 49，中等）

**题目**：给你一个字符串数组，请你将**字母异位词**组合在一起。可以按任意顺序返回结果列表。

> 字母异位词：字母种类和数量相同、顺序不同（如 `"eat"`、`"tea"`、`"ate"`）。

**示例**

```
输入: strs = ["eat","tea","tan","ate","nat","bat"]
输出: [["bat"],["nat","tan"],["ate","eat","tea"]]
```

**题眼**：**同类元素要映射到同一个 key**。两种 key 方案：

### 方案一：排序后作 key（最简单，先写这个）

```java
Map<String, List<String>> map = new HashMap<>();
for (String s : strs) {
    char[] cs = s.toCharArray();
    Arrays.sort(cs);                 // "eat" → "aet"
    String key = new String(cs);
    map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
}
return new ArrayList<>(map.values());
```

- 时间 O(n·k log k)（k 是字符串最大长度）
- 代码短，面试首选

### 方案二：计数作 key（更快，O(n·k)）

```java
int[] cnt = new int[26];
for (char c : s.toCharArray()) cnt[c - 'a']++;
String key = Arrays.toString(cnt);     // "[1, 0, 0, 1, ...]" 作为 key
```

- 每个字母的出现次数固定 26 个 → 拼成字符串作 key
- 时间 O(n·k)，但 `Arrays.toString` 也有开销，实际差距不大

**坑**：

- key 必须**能唯一标识"字母组成"**：`"eat"` 和 `"ate"` 排序后都是 `"aet"` ✅；但如果你用"字符和"作 key（`'e'+'a'+'t'`）就会碰撞（`"ad"` 与 `"bc"` 和相同）❌
- `map.computeIfAbsent(key, k -> new ArrayList<>()).add(s)` 比手写 `if (!map.containsKey)` 更简洁
- 返回值是 `List<List<String>>`，注意别返回 `map.values()` 本身（它是视图，类型也不对）

**复杂度**：O(n·k log k) / O(n·k)，空间 O(n·k)。

**验收**

- [ ] `["eat","tea","tan","ate","nat","bat"]` → 3 组：`["bat"]`、`["nat","tan"]`、`["ate","eat","tea"]`（组内、组间顺序不限，写测试时按"集合的集合"比较）
- [ ] `[""]` → `[[""]]`
- [ ] `["a"]` → `[["a"]]`
- [ ] `["abc","bca","cab","xyz"]` → 前三个一组、`["xyz"]` 一组
