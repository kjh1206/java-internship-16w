## 题一：环形链表 II（LeetCode 142）

**难度**：中等｜**标签**：链表、双指针、数学

### 题目描述

给定一个链表的头节点 `head`，返回链表开始入环的第一个节点。如果链表无环，则返回 `null`。

说明：不允许修改给定的链表。

**进阶**：你能用 `O(1)` 空间解决此题吗？

### 示例

```
输入：head = [3,2,0,-4]，尾节点连到索引 1 的节点（即值为 2 的节点）
输出：返回索引为 1 的链表节点
解释：链表中有一个环，其尾部连接到第二个节点。

输入：head = [1,2]，尾节点连到索引 0 的节点
输出：返回索引为 0 的链表节点

输入：head = [1]
输出：返回 null（无环）
```

> 注意：LeetCode 用一个 `pos` 参数构造环，但**你的函数只接收 `head`**，要自己检测环。

### 题眼（想不出来再看）

<details>
<summary>点开看提示</summary>

1. 先用快慢指针判断有没有环（这是 141 的做法）：`slow` 走一步、`fast` 走两步，有环必然相遇。
2. 相遇后有个数学结论：**从 `head` 出发和从相遇点出发，各走一步，它们会在环的入口相遇**。
3. 设头到入口距离 `a`，入口到相遇点距离 `b`，环长 `c`。相遇时 `slow` 走了 `a+b`，`fast` 走了 `a+b+nc`，而 `fast` 速度是 `slow` 的两倍 → `2(a+b) = a+b+nc` → `a = nc - b`，即 `a` 等于"从相遇点继续走到入口"的距离（绕了 n 圈）。
4. 所以：相遇后把 `fast`（或新指针）指回 `head`，两人都变成每次走一步，再相遇处就是入口。

</details>

### 要求

```java

        // 你的代码
    }
}
```

- 时间复杂度 `O(n)`，空间 `O(1)`
- 使用你昨天写的 `ListNode`（`int val; ListNode next;`）
- 自己写 `build(int[] arr, int pos)` 工具方法构造带环链表（`pos = -1` 表示无环），便于测试

## 题二：回文链表（LeetCode 234）

**难度**：简单｜**标签**：链表、双指针、反转链表

### 题目描述

给你一个单链表的头节点 `head`，请你判断该链表是否为回文链表。如果是，返回 `true`；否则，返回 `false`。

**进阶**：你能否用 `O(n)` 时间复杂度和 `O(1)` 空间复杂度解决此题？

### 示例

```
输入：head = [1,2,2,1]
输出：true

输入：head = [1,2]
输出：false
```

### 题眼（想不出来再看）

<details>
<summary>点开看提示</summary>

思路是"把后半段翻过来，然后和前半段逐一比较"：

1. **找中点**：快慢指针，`fast` 走两步、`slow` 走一步。偶数个节点时 `slow` 停在中间偏右（第二个中点），奇数个时停在正中间。
2. **反转后半段**：从 `slow` 开始，用 Day10 写的三指针/头插法反转。
3. **比较**：一个指针从 `head` 走，一个从反转后的头走，逐个比 `val`。
4. **可选**：比较完把后半段再反转回去（"不破坏原链表"在工程里是好习惯，LeetCode 不强制）。

边界：空链表和单节点都算回文。

</details>

### 要求

```java
public class Solution {
    public boolean isPalindrome(ListNode head) {
        // 你的代码
    }
}
```

- 时间 `O(n)`，空间 `O(1)`（不许把链表转成数组或 `ArrayList` 再双指针——那是 `O(n)` 空间）
- 允许调用你自己写的 `reverse(ListNode)`（把 Day10 的 206 解法抽成方法）

### 自测用例

| 输入 | 期望 |
|---|---|
| `[1,2,2,1]` | `true` |
| `[1,2]` | `false` |
| `[1]` | `true` |
| `[]` | `true` |
| `[1,2,3,2,1]` | `true`（奇数长度） |
| `[1,2,3,3,2,1]` | `true`（偶数长度） |
| `[1,1,1]` | `true` |
| `[1,2,1,2]` | `false` |

- [ ] 代码里没有把链表转成数组/集合
