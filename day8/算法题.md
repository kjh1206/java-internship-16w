## 先准备好节点类（两题共用）

LeetCode 上链表题都给你这样一个类，本地写的时候自己建一个：

```java
class ListNode {
    int val;
    ListNode next;

    ListNode() { }
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
```

再写两个工具方法（**这两行今天要写很多遍，值得单独练**）：

```java
// 从数组建链表：{1,2,6,3} → 1→2→6→3
static ListNode build(int[] a) {
    ListNode dummy = new ListNode(0);
    ListNode cur = dummy;
    for (int v : a) {
        cur.next = new ListNode(v);
        cur = cur.next;
    }
    return dummy.next;
}

// 链表转数组/字符串，方便打印比对
static String toStr(ListNode head) {
    StringBuilder sb = new StringBuilder();
    for (ListNode p = head; p != null; p = p.next) {
        if (sb.length() > 0) sb.append("→");
        sb.append(p.val);
    }
    return sb.length() == 0 ? "(空)" : sb.toString();
}
```

## 第 1 题 · LeetCode 203 移除链表元素

**难度**：简单　**标签**：链表、虚拟头结点

### 题目

给你一个链表的头节点 `head` 和一个整数 `val`，请你删除链表中所有满足 `Node.val == val` 的节点，并返回**新的头节点**。

### 示例

```
输入：head = [1,2,6,3,4,5,6], val = 6
输出：[1,2,3,4,5]

输入：head = [], val = 1
输出：[]

输入：head = [7,7,7,7], val = 7
输出：[]
```

### 题眼（今天最重要的一条）

**头节点也可能被删**。如果不做特殊处理，你会面临两种情况：

- 删中间节点：让 `前一个` 指向 `下一个`
- 删头节点：没有"前一个"，得单独改 `head`

两种逻辑写起来很烦，而且容易漏。**解法：加一个虚拟头结点 `dummy`**，让所有节点都"有前一个"：

```
dummy → 1 → 2 → 6 → 3 → 4 → 5 → 6 → null
```

删完之后返回 `dummy.next` 就是真正的新头。

### 思路

```java
ListNode dummy = new ListNode(0, head);
ListNode prev = dummy;
while (prev.next != null) {
    if (prev.next.val == val) {
        prev.next = prev.next.next;   // 跳过被删节点，prev 不动
    } else {
        prev = prev.next;             // 保留，往前走
    }
}
return dummy.next;
```

**关键细节**：

- 删完**不能** `prev = prev.next`，因为新的 `prev.next` 可能还要删（连续两个 6）
- `while` 条件看的是 `prev.next != null`，不是 `prev != null`

### 自测用例

| head | val | 期望 |
|---|---|---|
| `[1,2,6,3,4,5,6]` | 6 | `[1,2,3,4,5]` |
| `[]` | 1 | `[]` |
| `[7,7,7,7]` | 7 | `[]` |
| `[1,2,2,1]` | 2 | `[1,1]` |
| `[6,1,6]` | 6 | `[1]` |

最后两组是专门坑人的：连续删除、删头又删尾。

## 第 2 题 · LeetCode 206 反转链表

**难度**：简单　**标签**：链表、三指针 / 递归

### 题目

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

### 示例

```
输入：head = [1,2,3,4,5]
输出：[5,4,3,2,1]

输入：head = [1,2]
输出：[2,1]

输入：head = []
输出：[]
```

### 题眼

遍历一遍，把每个节点的 `next` **掉头**。但直接改会丢失后面的节点，所以需要三个指针：

```
prev（已反转部分的头）  cur（当前）  next（先存起来的下一个）
null ← 1    2 → 3 → null
```

每一步：

```java
ListNode next = cur.next;   // 1. 先存下一个，不然改完就找不到了
cur.next = prev;            // 2. 掉头
prev = cur;                 // 3. prev 前进
cur = next;                 // 4. cur 前进
```

循环到 `cur == null`，返回 `prev`（此时它是新头）。

**必须按 1→2→3→4 的顺序**。第 1 步写晚了，链表就断了。

### 版本 2：递归（想挑战再看）

```java
static ListNode reverse(ListNode head) {
    if (head == null || head.next == null) return head;   // 出口
    ListNode newHead = reverse(head.next);                // 先反转后面
    head.next.next = head;                                // 让后一个指回自己
    head.next = null;                                     // 断开原来的指向
    return newHead;
}
```

递归版更短，但**面试时建议先写迭代版**——迭代版不涉及栈、不会栈溢出、能手推。

### 自测用例

| head | 期望 |
|---|---|
| `[1,2,3,4,5]` | `[5,4,3,2,1]` |
| `[1,2]` | `[2,1]` |
| `[]` | `[]` |
| `[1]` | `[1]` |
