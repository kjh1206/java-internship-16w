## 题一：454. 四数相加 II（中等）

**链接**：https://leetcode.cn/problems/4sum-ii/

### 题目

给你四个整数数组 `nums1`、`nums2`、`nums3`、`nums4`，长度都是 `n`。
请你计算有多少个元组 `(i, j, k, l)` 满足：

```
0 <= i, j, k, l < n
nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0
```

**示例 1**

```
输入: nums1 = [1,2], nums2 = [-2,-1], nums3 = [-1,2], nums4 = [0,2]
输出: 2
解释: 两个元组如下：
1. (0,0,0,1): 1 + (-2) + (-1) + 2 = 0
2. (1,1,0,0): 2 + (-1) + (-1) + 0 = 0
```

**示例 2**

```
输入: nums1 = [0], nums2 = [0], nums3 = [0], nums4 = [0]
输出: 1
```

**约束**

- `n == nums1.length == nums2.length == nums3.length == nums4.length`
- `1 <= n <= 200`
- `-2^28 <= nums1[i], ..., nums4[i] <= 2^28`

### 题眼

**四个数加起来等于 0** ⇔ `(a + b) == -(c + d)`。

于是把"四层循环 O(n⁴)"拆成"两组两层循环 O(n²)"：

1. 先算 `nums1[i] + nums2[j]` 的所有和，用 `HashMap<和, 出现次数>` 统计；
2. 再算 `nums3[k] + nums4[l]`，去表里找 `-(和)` 的次数，累加到答案。

**为什么用 Map 而不是 Set**：同一个和可能出现多次，每一种组合都要计数。

### 复杂度

| 版本 | 时间 | 空间 |
|---|---|---|
| 四层暴力 | O(n⁴) | O(1) |
| 两两分组 + HashMap | **O(n²)** | O(n²) |

n=200 时：n⁴ = 16 亿，n² = 4 万。差距在这。

### 要求

1. 先用"两两分组"写出来，`n=200` 的随机数据能秒出；
2. 打印 `HashMap` 的大小，观察不同的和对有多少种（体会空间换时间）；
3. 自己造一组能返回 0 的数据，确认代码没漏算。

### 验收

- [ ] AC，且能讲清为什么复杂度从 n⁴ 降到 n²
- [ ] 能解释"为什么 value 存次数而不是存一个 boolean"
- [ ] 知道这题不能排序双指针（四个数组相互独立，不是同一个数组）

## 题二：36. 有效的数独（中等）

**链接**：https://leetcode.cn/problems/valid-sudoku/

### 题目

判断一个 `9 x 9` 的数独是否有效。只需要根据以下规则验证已经填入的数字是否有效即可：

1. 每一行包含数字 `1-9`，不重复；
2. 每一列包含数字 `1-9`，不重复；
3. 每一个 `3 x 3` 的粗实线宫内的数字 `1-9`，不重复。

**注意**：
- 一个有效的数独不一定是可解的，只需要验证已填入的数字；
- 空白格用 `'.'` 表示。

**示例 1**

```
输入: board =
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出: true
```

**示例 2**

```
输入: board =
[["8","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出: false
解释: 左上角的 3x3 宫内有两个 8。
```

### 题眼

**一次遍历，三个维度同时去重**：

```java
rows[i][d]    // 第 i 行是否出现过数字 d
cols[j][d]    // 第 j 列是否出现过数字 d
boxes[k][d]   // 第 k 个宫是否出现过数字 d
```

关键就是**宫的下标怎么算**：

```java
int box = (i / 3) * 3 + (j / 3);   // 0..8
```

也可以写成 `(i/3, j/3)` 两维，本质一样。

### 三种实现对比

| 实现 | 空间 | 说明 |
|---|---|---|
| `boolean[9][9]` ×3 | 3×81 | 最快，无装箱 |
| `HashSet<Character>` ×27 | 较大 | 好写，但每格建对象 |
| 位运算 `int[9]`（`mask \|= 1 << d`） | 3×9 个 int | 面试加分项 |

### 要求

1. 先用 `boolean[9][9]` 写一版；
2. 再改位运算版，对比可读性与速度（1 万次调用计时）；
3. 自己造 3 个用例：合法、行冲突、宫冲突。

### 验收

- [ ] 两版都 AC
- [ ] 能当场写出宫下标公式 `(i/3)*3 + j/3`
- [ ] 能说出"为什么这题只是验证，不是求解"
