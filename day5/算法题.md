## 第 1 题 · LeetCode 209 长度最小的子数组（滑动窗口）

**难度**：中等　**标签**：数组、滑动窗口、双指针

### 题目

给定一个含有 `n` 个**正整数**的数组 `nums` 和一个正整数 `target`。

找出该数组中满足其和 **≥ target** 的**长度最小的连续子数组** `[nums[l], nums[l+1], ..., nums[r]]`，返回其长度。如果不存在符合条件的子数组，返回 `0`。

### 示例

```
输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 的和是 7，长度 2，是所有满足条件的子数组里最短的。

输入：target = 4, nums = [1,4,4]
输出：1

输入：target = 11, nums = [1,1,1,1,1,1,1,1]
输出：0
```

### 题眼

- 数组元素**全是正数** → 窗口右移时和变大，左移时和变小，**有单调性**，才能用滑动窗口
- `left`、`right` 两个指针，`right` 负责扩窗，`left` 负责缩窗
- 扩到 `sum >= target` 后，**先把长度记下来**，再不停地缩左边，看能不能更短

### 暴力为什么不优

枚举所有子数组：`O(n²)` 个子数组，每个求和 `O(n)`，总 `O(n³)`。哪怕前缀和优化到 `O(n²)`，`n = 10⁵` 也过不了。

滑动窗口是 `O(n)`：`left` 和 `right` 各自只往右走一次，"门框"从不回头。

### 自测用例

| nums | target | 期望 |
|---|---|---|
| `[2,3,1,2,4,3]` | 7 | 2 |
| `[1,4,4]` | 4 | 1 |
| `[1,1,1,1,1,1,1,1]` | 11 | 0 |
| `[1,2,3]` | 6 | 3 |
| `[5]` | 5 | 1 |

### 写完自查

- `[1,2,3]`、`target=6` 时，整个数组刚好等于 6，答案是 3 —— 你的循环有没有漏掉"最后一个窗口"？
- 找不到时返回的是 `0` 还是某个默认值？**先把 `min = Integer.MAX_VALUE`，最后判断是不是还是它**。
- 数组为空时怎么办？

## 第 2 题 · LeetCode 485 最大连续 1 的个数

**难度**：简单　**标签**：数组、一次遍历

### 题目

给定一个二进制数组 `nums`，计算其中**最大连续 1 的个数**。

### 示例

```
输入：nums = [1,1,0,1,1,1]
输出：3
解释：开头的两个 1 和后面的三个 1，最长连续 3 个。

输入：nums = [1,0,1,1,0,1]
输出：2
```

### 题眼

- 只需要**一次遍历**：遇到 1 就 `cur++`，遇到 0 就 `cur = 0`
- 每次更新完 `cur`，顺手用 `max = Math.max(max, cur)` 记下最大值
- 别用"两个循环找区间"的写法，那是 `O(n²)`

### 变体思考（做完再看）

1. 如果数组允许**翻转 k 个 0**，问最长全 1 子数组，怎么做？（这是第 3 周的滑动窗口题，题号 1004）
2. 如果问"最大连续相同数字"（不一定是 1），代码要改哪一行？
