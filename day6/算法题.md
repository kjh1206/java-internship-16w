## 第 1 题 · LeetCode 704 二分查找

**难度**：简单　**标签**：数组、二分

### 题目

给定一个 `n` 个元素**有序（升序）**且**无重复**的整型数组 `nums` 和一个目标值 `target`。

如果 `target` 存在，返回它的下标；否则返回 `-1`。

要求：时间复杂度 `O(log n)`。

### 示例

```
输入：nums = [-1,0,3,5,9,12], target = 9
输出：4
解释：9 出现在 nums 中，下标为 4。

输入：nums = [-1,0,3,5,9,12], target = 2
输出：-1
解释：2 不存在，返回 -1。
```

### 题眼

- **有序**是能二分的前提。无序数组不能二分（除非先排序，那就 O(n log n) 了，不如直接扫）
- 三个变量：`left = 0`、`right = n - 1`、`mid`
- 循环条件 `while (left <= right)`：**`<=` 不是 `<`**，因为区间里还剩一个元素时也要判断
- `mid = left + (right - left) / 2`（避免 `left + right` 溢出，虽然这题不会溢出，但要养成习惯）
- 命中返回 `mid`；`nums[mid] < target` → `left = mid + 1`；否则 `right = mid - 1`

### 昨天你已经手推过一遍

找 8 在 `{1,3,5,7,9,11,13}` 里的过程：`(0,6) mid=3 → (4,6) mid=5 → (4,4) mid=4 → (4,3)` 返回 -1。

今天把它写成**迭代**版（不用递归），然后对比递归版。

### 自测用例

| nums | target | 期望 |
|---|---|---|
| `[-1,0,3,5,9,12]` | 9 | 4 |
| `[-1,0,3,5,9,12]` | 2 | -1 |
| `[5]` | 5 | 0 |
| `[5]` | -5 | -1 |
| `[1,3,5,7,9,11,13]` | 13 | 6 |
| `[1,3,5,7,9,11,13]` | 1 | 0 |

### 写完自查

- `[5]` 找 5：`left=0, right=0`，循环进得去吗？如果写成 `while (left < right)`，直接返回 -1 —— 这就是 `<=` 的意义
- 找首元素、找尾元素都要测，边界最容易错
- `mid + 1` / `mid - 1` 是为了**保证区间收缩**，写成 `left = mid` 会死循环

## 第 2 题 · LeetCode 344 反转字符串

**难度**：简单　**标签**：双指针、字符串

### 题目

编写一个函数，其作用是将输入的字符数组 `s` **原地**反转。不要给另外的数组分配额外空间，你必须原地修改输入数组。

### 示例

```
输入：s = ['h','e','l','l','o']
输出：['o','l','l','e','h']

输入：s = ['H','a','n','n','a','h']
输出：['h','a','n','n','a','H']
```

### 题眼

- 就是昨天数组练习里写过的 `reverse(int[])`，换成 `char[]`
- 左右指针 `i = 0`、`j = s.length - 1`，交换后 `i++`、`j--`
- 循环条件 `while (i < j)`：中间那个字符不用动；写成 `i <= j` 也不报错，但多交换一次自己
- **原地**意味着不能 `new char[]`——面试官会看这一点

### 为什么这题值得做

它是"双指针相向而行"的最小模型。同一个骨架换一下就能解：

| 题 | 改哪里 |
|---|---|
| 344 反转字符串 | 交换字符 |
| 125 验证回文串 | 不交换，比较 `s[i] == s[j]`，不等就 false |
| 167 两数之和 II | 不交换，比较和与 target，决定动 `i` 还是 `j` |
| 11 盛最多水的容器 | 不算交换，算面积取 max，移动矮的那边 |

**一题顶四题**，这就是为什么双指针要练熟。

### 自测用例

| 输入 | 期望 |
|---|---|
| `['h','e','l','l','o']` | `['o','l','l','e','h']` |
| `['H','a','n','n','a','h']` | `['h','a','n','n','a','H']` |
| `['a']` | `['a']` |
| `['a','b']` | `['b','a']` |
