## 题一：155. 最小栈（中等偏易）

**链接**：https://leetcode.cn/problems/min-stack/

### 题目

设计一个支持 `push`、`pop`、`top` 操作，并能在 **O(1)** 时间内检索到最小元素的栈。

实现 `MinStack` 类：

- `MinStack()` 初始化堆栈对象
- `void push(int val)` 将元素 val 推入堆栈
- `void pop()` 删除堆栈顶部的元素
- `int top()` 获取堆栈顶部的元素
- `int getMin()` 获取堆栈中的最小元素

**示例**

```
输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin();   // 返回 -3
minStack.pop();
minStack.top();      // 返回 0
minStack.getMin();   // 返回 -2
```

### 提示

- `-2^31 <= val <= 2^31 - 1`
- `pop`、`top`、`getMin` 操作总是在**非空**栈上调用

### 题眼

- 关键是 `getMin` 要 O(1)：不能每次遍历找最小
- 辅助栈**同步压入**"当前最小值"：`minStack.push(Math.min(val, minStack.peek()))`
- 注意 `pop` 时两个栈要一起弹

### 要求

1. 用**两个栈**实现（辅助栈存"截至当前的最小值"）
2. 不能改方法签名
3. 自己补 5 组测试（含全部负数、重复最小值、单元素）

### 验收

- [ ] `getMin` 是 O(1)
- [ ] 连续 `push` 相同最小值后 `pop` 一次，`getMin` 仍然正确

## 题二：232. 用栈实现队列（简单）

**链接**：https://leetcode.cn/problems/implement-queue-using-stacks/

### 题目

请你仅使用**两个栈**实现先入先出队列。队列应当支持一般队列支持的所有操作（`push`、`pop`、`peek`、`empty`）。

实现 `MyQueue` 类：

- `void push(int x)` 将元素 x 推到队列的末尾
- `int pop()` 从队列的开头移除并返回元素
- `int peek()` 返回队列开头的元素
- `boolean empty()` 如果队列为空，返回 `true`；否则返回 `false`

**示例**

```
输入：
["MyQueue","push","push","peek","pop","empty"]
[[],[1],[2],[],[],[]]

输出：
[null,null,null,1,1,false]

解释：
MyQueue myQueue = new MyQueue();
myQueue.push(1);   // queue is: [1]
myQueue.push(2);   // queue is: [1, 2]（最左边是队头）
myQueue.peek();    // 返回 1
myQueue.pop();     // 返回 1，queue is [2]
myQueue.empty();   // 返回 false
```

### 提示

- `1 <= x <= 9`
- 最多调用 `100` 次 `push`、`pop`、`peek` 和 `empty`
- 假设所有操作都是有效的

### 题眼

- 一个 **in 栈**负责 push，一个 **out 栈**负责 pop/peek
- **只有当 out 为空时，才把 in 全部倒进 out**（顺序反转两次 = 正序）
- 每次 pop/peek 都倒一遍会退化成 O(n²)；"out 空才倒"让每个元素最多被搬两次 → 均摊 O(1)

### 要求

1. 用两个 `ArrayDeque`（不要用 `Stack`，它已过时且带同步开销）
2. 注释里写清"为什么 out 不空时不能倒"
3. 自己补 5 组测试：交替 push/pop、连续 pop、空队列判断、push 后立刻 peek、清空后再 push

### 验收

- [ ] 100 次混合操作下总耗时可忽略（说明均摊 O(1)）
- [ ] 能口述"每个元素最多进 out 一次、出 out 一次"
