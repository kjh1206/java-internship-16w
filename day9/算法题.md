## 题一：两两交换链表中的节点（LeetCode 24，中等）

### 题目

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。
你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**示例 1**

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

**示例 2**

```
输入：head = []
输出：[]
```

**示例 3**

```
输入：head = [1]
输出：[1]
```

**示例 4**

```
输入：head = [1,2,3]
输出：[2,1,3]
```

### 提示

- 链表中节点的数目在范围 `[0, 100]` 内
- `0 <= Node.val <= 100`

### 题眼

交换 `1 → 2` 这两根节点，实际要动**三条线**：

```
交换前：  pre → 1 → 2 → 3
交换后：  pre → 2 → 1 → 3
```

1. `pre.next = 2`
2. `2.next = 1`
3. `1.next = 3`（原来的 3，也就是 2 后面那个）

**顺序不能乱**：如果先写 `1.next = 3`，你就丢了 `2` 的入口。所以必须先用临时变量把 `2` 和 `3` 存下来。

最省事的写法是加一个**虚拟头结点 `dummy`**：让 `pre` 一开始指向 `dummy`，这样"交换前两个节点"和"交换中间任意两个"逻辑完全一致，不用为头结点单独写 if。

### 要求

1. 用**迭代**写一版，必须用 `dummy` 虚拟头结点。
2. 用**递归**再写一版（`swapPairs(head)` 的语义：返回交换后的新头）。
3. 两版都要能处理空链表、单节点、奇数个节点三种边界。
4. 写一个 `ListNode` 类 + 数组转链表、链表转数组的工具方法，用示例 1/2/3/4 做断言。

### 验收

- [ ] 四组用例全部通过，输出与示例一致
- [ ] 能不看代码，在纸上画出 `pre / first / second` 三个指针的移动过程
- [ ] 能说出为什么必须先保存 `second` 才能改 `first.next`

## 题二：删除链表的倒数第 N 个结点（LeetCode 19，中等）

### 题目

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1**

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2**

```
输入：head = [1], n = 1
输出：[]
```

**示例 3**

```
输入：head = [1,2], n = 1
输出：[1]
```

### 提示

- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

### 题眼

链表没有"长度"属性，倒数第 n 个没法直接跳。两种思路：

**思路 A：两次遍历** —— 先数长度 `len`，再正向走到第 `len - n` 个节点删掉。简单，但走两遍。

**思路 B：快慢指针（推荐）** —— 一次遍历：

```
1. 快指针先走 n 步
2. 快慢指针同时走，直到快指针走到最后一个节点
3. 此时慢指针正好在"要删除节点的前一个"
```

为什么？因为快慢之间始终隔着 `n` 个节点，快指针到头时，慢指针距离末尾就是 `n`，即倒数第 `n+1` 个 = 待删节点的前驱。

同样建议用 `dummy`：如果删的是**头结点**（`n == len`），没有前驱，`dummy` 能统一处理。

**易错点**：删除时是 `slow.next = slow.next.next`，不是 `slow = slow.next.next`——后者只改了局部变量。

### 要求

1. 先写**两次遍历**版，跑通。
2. 再写**快慢指针**版，跑通，并在注释里写清"快指针为什么走 n 步"。
3. 两版都必须用 `dummy`。
4. 用例至少覆盖：删中间、删头、删尾、只剩一个节点。

### 验收

- [ ] 四类用例（中间/头/尾/单节点）全过
- [ ] 能口述"快慢指针为什么能找到倒数第 n 个"
- [ ] 能解释 `slow.next = slow.next.next` 和 `slow = slow.next.next` 的区别
