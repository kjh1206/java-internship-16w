## 题 1：合并两个有序数组（LeetCode 88，简单）

给你两个按**非递减顺序**排列的整数数组 `nums1` 和 `nums2`，另有两个整数 `m` 和 `n`，分别表示 `nums1` 和 `nums2` 中的元素数目。

请你**原地**合并 `nums2` 到 `nums1` 中，使合并后的数组同样按非递减顺序排列。

注意：`nums1` 的初始长度为 `m + n`，其中前 `m` 个元素是需要合并的，**后 `n` 个位置是 0，用来放 `nums2` 的元素**。

**示例 1**

```
输入：nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3
输出：[1,2,2,3,5,6]
```

**示例 2**

```
输入：nums1 = [1], m = 1, nums2 = [], n = 0
输出：[1]
```

**示例 3**

```
输入：nums1 = [0], m = 0, nums2 = [1], n = 1
输出：[1]
```

**要求**

- 不要返回新数组，直接在 `nums1` 上改（函数签名 `void merge(int[] nums1, int m, int[] nums2, int n)`）
- 时间复杂度 O(m + n)

**题眼（卡住再看）**

> 如果从前往后合并，`nums1` 前面的元素会被覆盖，你得先把 `nums1` 整个往后挪——那是 O(m·n)。
> 但 `nums1` 的**后半段是空的**！从**后往前**放最大的元素，就不会覆盖任何还没处理的数据。

**自测用例**

```java
nums1 = {1,2,3,0,0,0}, m = 3, nums2 = {2,5,6}, n = 3   → {1,2,2,3,5,6}
nums1 = {4,5,6,0,0,0}, m = 3, nums2 = {1,2,3}, n = 3   → {1,2,3,4,5,6}
nums1 = {1}, m = 1, nums2 = {}, n = 0                  → {1}
nums1 = {0}, m = 0, nums2 = {1}, n = 1                 → {1}
```

## 题 2：有序数组的平方（LeetCode 977，简单）

给你一个按**非递减顺序**排序的整数数组 `nums`（可能含负数），返回**每个数字的平方**组成的新数组，要求也按**非递减顺序**排序。

**示例 1**

```
输入：nums = [-4,-1,0,3,10]
输出：[0,1,9,16,100]
解释：平方后得到 [16,1,0,9,100]，排序后得到 [0,1,9,16,100]
```

**示例 2**

```
输入：nums = [-7,-3,2,3,11]
输出：[4,9,9,49,121]
```

**要求**

- 返回新数组，时间复杂度 O(n)（**不允许**先平方再 `Arrays.sort`，那是 O(n log n)）

**题眼（卡住再看）**

> 数组有序，但平方之后**最大值一定在两端**（最负的数和最大的正数）。
> 所以用**左右双指针**：每次比较两端的平方，谁大就把谁放到结果数组的**末尾**，然后那一端向内收。
> 从后往前填结果数组——和题 1 从后往前放是同一个套路。

**自测用例**

```java
{-4,-1,0,3,10}  → {0,1,9,16,100}
{-7,-3,2,3,11}  → {4,9,9,49,121}
{-5,-4,-3}      → {9,16,25}      全负数
{1,2,3}         → {1,4,9}        全正数
{0}             → {0}            单元素
```
