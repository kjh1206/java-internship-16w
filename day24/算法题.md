## 题一：739. 每日温度（中等）

**链接**：https://leetcode.cn/problems/daily-temperatures/

### 题目

给定一个整数数组 `temperatures`，表示每天的温度，返回一个数组 `answer`，其中 `answer[i]` 是指对于第 `i` 天，**下一个更高温度出现在几天后**。如果气温在这之后都不会升高，请在该位置用 `0` 来代替。

**示例 1**

```
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
解释：第 0 天 73 度，下一个更高温度是第 1 天的 74 度，所以 answer[0] = 1
      第 2 天 75 度，下一个更高是第 6 天的 76 度，隔着 4 天 → 4
      第 6 天 76 度之后没有更高 → 0
```

**示例 2**

```
输入：temperatures = [30,40,50,60]
输出：[1,1,1,0]
```

**示例 3**

```
输入：temperatures = [30,60,90]
输出：[1,1,0]
```

### 提示

- `1 <= temperatures.length <= 10^5`
- `30 <= temperatures[i] <= 100`

### 题眼

- 暴力 O(n²)：对每天向后找第一个更大值，n=10^5 会超时
- **单调栈**：栈里存**下标**，保证栈内温度**单调递减**（栈底最大，栈顶最小）
- 遍历到第 `i` 天时，只要栈顶那天的温度**低于**今天，就说明"栈顶那天的下一个更高温就是今天"——弹出并写入 `i - 栈顶下标`
- 每个下标**进栈一次、出栈一次** → O(n)
- **栈里存下标不存温度**，因为要算"隔了几天"

模板（背下来）：

```java
Deque<Integer> stack = new ArrayDeque<>();
for (int i = 0; i < n; i++) {
    while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
        int j = stack.pop();
        answer[j] = i - j;
    }
    stack.push(i);
}
```

### 要求

1. 用 `ArrayDeque` 当栈，**存下标**
2. 用 while 而不是 if（一天可能"结算"好几天）
3. 自己补 6 组测试：示例 1~3、全相同 `[50,50,50]`、递减 `[90,80,70]`、单元素 `[30]`

### 验收

- [ ] 6 组测试全过
- [ ] 能口述"为什么每个元素最多进出栈一次，所以是 O(n)"
- [ ] 能画出 `[73,74,75,71,69,72,76,73]` 的栈变化过程（至少前 5 天）

## 题二：496. 下一个更大元素 I（简单）

**链接**：https://leetcode.cn/problems/next-greater-element-i/

### 题目

`nums1` 中数字 `x` 的**下一个更大元素**是指 `x` 在 `nums2` 中对应位置**右侧**的第一个比 `x` 大的元素。

给你两个**没有重复元素**的数组 `nums1` 和 `nums2`，下标从 0 开始，其中 `nums1` 是 `nums2` 的子集。

对每个 `0 <= i < nums1.length`，找出满足 `nums1[i] == nums2[j]` 的下标 `j`，并且在 `nums2` 中确定 `nums2[j]` 的**下一个更大元素**。如果不存在下一个更大元素，那么本次查询的答案是 `-1`。

返回一个长度为 `nums1.length` 的数组 `ans` 作为答案，满足 `ans[i]` 是如上所述的**下一个更大元素**。

**示例 1**

```
输入：nums1 = [4,1,2], nums2 = [1,3,4,2]
输出：[-1,3,-1]
解释：
  4 在 nums2 中右侧没有更大元素 → -1
  1 的下一个更大是 3
  2 右侧没有更大 → -1
```

**示例 2**

```
输入：nums1 = [2,4], nums2 = [1,2,3,4]
输出：[3,-1]
```

### 提示

- `1 <= nums1.length <= nums2.length <= 1000`
- `0 <= nums1[i], nums2[i] <= 10^4`
- `nums1` 和 `nums2` 中所有整数**互不相同**
- `nums1` 中的所有整数同样出现在 `nums2` 中

### 题眼

- 和上一题几乎一样，只是：**先对 `nums2` 求每个元素的"下一个更大元素"，存进 Map**，再用 `nums1` 去查
- 因为是"求值"不是"求距离"，栈里可以存**值**（也可以存下标，看习惯）
- `Map<Integer, Integer> nextGreater`：key = 元素值，value = 它的下一个更大元素（没有则不放，查不到就是 -1）

```java
Map<Integer, Integer> next = new HashMap<>();
Deque<Integer> stack = new ArrayDeque<>();
for (int x : nums2) {
    while (!stack.isEmpty() && stack.peek() < x) {
        next.put(stack.pop(), x);          // 弹出的元素，它的下一个更大就是 x
    }
    stack.push(x);
}
```

### 要求

1. 单调栈 + `HashMap`，时间复杂度 O(n + m)
2. 栈里存值（体会与上一题"存下标"的区别）
3. 自己补 5 组测试：示例 1~2、`nums1` 只有一个元素、`nums2` 递增、`nums2` 递减

### 验收

- [ ] 5 组测试全过
- [ ] 能说清"为什么这题可以存值，上一题必须存下标"
- [ ] 能回答：如果有重复元素，这个写法还成立吗？为什么？
