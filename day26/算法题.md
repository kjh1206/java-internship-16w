## 题一：LC 71 简化路径（中等）

### 题目

给你一个字符串 `path`，表示 Unix 风格的文件系统绝对路径（以 `/` 开头），把它转成**规范路径**。

规则：

- 路径由 `/`、`.`、`..`、字母数字组成
- `.` 表示当前目录 —— 忽略
- `..` 表示上一级目录 —— 弹出最后一级；如果已经在根目录，`..` 无效（留在根）
- 多个连续 `/` 视为一个 `/`
- 结果必须以 `/` 开头、**不以 `/` 结尾**、根目录就是 `"/"`
- 其他部分（如 `home`、`a`、`...`）是普通目录名，直接入栈

### 示例

```
输入: path = "/home/"
输出: "/home"

输入: path = "/../"
输出: "/"                （根目录的 .. 无效）

输入: path = "/home//foo/"
输出: "/home/foo"        （连续斜杠合并）

输入: path = "/a/./b/../../c/"
输出: "/c"               （a 入，. 忽略，b 入，.. 弹 b，.. 弹 a，c 入）

输入: path = "/..."
输出: "/..."             （"..." 是合法目录名，不是 ..）
```

### 提示

- `path.split("/")` 会产生大量空串，逐段判断即可（空串、"." 直接跳过）
- 只有**完全等于** `".."` 才是回退，`"..."` 是普通目录

### 题眼（卡住再看）

1. 典型模型：**栈里存"目录名"，遇到 `..` 就弹一个**
2. 弹栈前必须判空（`/../` 的情况）
3. 最后从栈底往栈顶拼 `"/" + 名字`，空栈直接返回 `"/"`

### 要求

- 用 `ArrayDeque<String>` 当栈（**不要**用 `Stack`）
- 时间复杂度 O(n)，空间 O(n)
- 边界：`"/"`、`"/../.."`、`"/a/../../b"` 都要对

### 验收

- [ ] 5 个示例全过
- [ ] `"/"` → `"/"`
- [ ] 连续 4 个 `..` 不越界
- [ ] 能口述"为什么用 Deque 不用 Stack"

## 题二：LC 1047 删除字符串中的所有相邻重复项（简单）

### 题目

给出由小写字母组成的字符串 `s`，**反复删除**相邻且相同的两个字母，直到无法继续删除。返回最终字符串（答案唯一）。

### 示例

```
输入: "abbaca"
输出: "ca"
过程: "abbaca" -> "aaca"（删 bb）-> "ca"（删 aa）

输入: "azxxzy"
输出: "ay"
过程: "azxxzy" -> "azzy"（删 xx）-> "ay"（删 zz）

输入: "a"
输出: "a"

输入: "aaaaaaaa"
输出: ""
```

### 提示

- 不要真的反复扫描字符串（O(n²)）—— 一次遍历就能做完
- 关键：当前字符和"已处理部分的最后一个字符"比较

### 题眼（卡住再看）

1. 用**栈**：当前字符 == 栈顶 → 弹出；否则压入
2. 遍历结束后栈里剩下的（从底到顶）就是答案
3. 用 `StringBuilder` 当栈：`charAt(len-1)` 看栈顶、`deleteCharAt(len-1)` 弹栈、最后 `toString()` —— 比 `ArrayDeque<Character>` 省一次拆装箱

### 要求

- 一次遍历，O(n)
- 用 `StringBuilder` 模拟栈（不要用递归）
- 边界：`""`、`"aa"`、`"abba"`、`"aaaaaaaa"`

### 验收

- [ ] `"abbaca"` → `"ca"`
- [ ] `"aaaaaaaa"` → `""`
- [ ] 能解释"为什么一次遍历就够"（每个字符最多压入、弹出各一次）
