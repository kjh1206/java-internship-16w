## 题目一：链表的中间结点（LeetCode 876，简单）

**题目**：给定一个头结点为 `head` 的非空单链表，返回链表的中间结点。
如果有两个中间结点，则返回**第二个**中间结点。

**示例 1**

```
输入：head = [1,2,3,4,5]
输出：[3,4,5]
解释：中间结点是 3（奇数个，正好在正中间）
```

**示例 2**

```
输入：head = [1,2,3,4,5,6]
输出：[4,5,6]
解释：有两个中间结点 3 和 4，返回第二个，即 4
```

**题眼**：快慢指针。`slow` 走一步，`fast` 走两步，`fast` 到末尾时 `slow` 正好在中间。
**奇数长度的"第二个中间结点"**：用 `while (fast != null && fast.next != null)` 这个条件，而不是 `fast.next != null && fast.next.next != null`——后者返回的是第一个中间结点。

**复杂度**：时间 O(n)，空间 O(1)。数组解法（先数长度再走 n/2 步）是两趟遍历，虽然也是 O(n)，但面试官更想看快慢指针。

**验收**

- [ ] `[1]` → `[1]`
- [ ] `[1,2]` → `[2]`
- [ ] `[1,2,3,4,5]` → `[3,4,5]`
- [ ] `[1,2,3,4,5,6]` → `[4,5,6]`

## 题目二：删除排序链表中的重复元素（LeetCode 83，简单）

**题目**：给定一个已排序的链表的头 `head`，删除所有重复的元素，使每个元素只出现一次。返回已排序的链表。

**示例 1**

```
输入：head = [1,1,2]
输出：[1,2]
```

**示例 2**

```
输入：head = [1,1,2,3,3]
输出：[1,2,3]
```

**题眼**：

1. 链表**已排序**，所以重复元素一定**相邻**——不需要哈希表，一个指针就够。
2. 只保留每个值的第一个：`if (cur.val == cur.next.val) cur.next = cur.next.next;`（**cur 不动**，继续和新的 next 比）
3. 不相等才 `cur = cur.next`。

**和 LC 203（移除链表元素）的区别**：203 要删的元素可能出现在**头部**，所以需要 dummy；83 的头结点**一定能保留**（它是第一个值），所以**不需要 dummy**。这也是面试官判断你"是不是真的理解了 dummy 为什么存在"的地方。

**边界**：空链表 `[]` → `[]`；全部相同 `[1,1,1]` → `[1]`；没有重复 `[1,2,3]` → 原样。

**复杂度**：时间 O(n)，空间 O(1)。

**验收**

- [ ] `[]` → `[]`
- [ ] `[1]` → `[1]`
- [ ] `[1,1,2]` → `[1,2]`
- [ ] `[1,1,2,3,3]` → `[1,2,3]`
- [ ] `[1,1,1]` → `[1]`
- [ ] `[1,2,3]` → `[1,2,3]`（无重复也不能坏）
