## 第一题：LeetCode 141 · 环形链表（简单）

### 题目

给你一个链表的头节点 `head`，判断链表中是否有环。

如果链表中有某个节点，可以通过连续跟踪 `next` 指针再次到达，则链表中存在环。为了表示给定链表中的环，评测系统内部使用整数 `pos` 来表示链表尾连接到链表中的位置（索引从 0 开始）。**注意：`pos` 不作为参数进行传递**，仅仅是为了标识链表的实际情况。

如果链表中存在环，则返回 `true`。否则，返回 `false`。

**示例 1：**

```
输入：head = [3,2,0,-4], pos = 1
输出：true
解释：链表中有一个环，其尾部连接到第二个节点。
```

**示例 2：**

```
输入：head = [1,2], pos = 0
输出：true
解释：链表中有一个环，其尾部连接到第一个节点。
```

**示例 3：**

```
输入：head = [1], pos = -1
输出：false
解释：链表中没有环。
```

**提示：**

- 链表中节点的数目范围是 `[0, 10^4]`
- `-10^5 <= Node.val <= 10^5`
- `pos` 为 `-1` 或者链表中的一个有效索引
- **进阶**：你能用 O(1) 内存解决此问题吗？

### 题眼

> 两个人在环形跑道上，一个快一个慢。如果跑道是直的，快的先到终点；如果跑道是环的，快的迟早会"追上"慢的。

**为什么一定追得上？** 每走一步，快慢之间的距离缩小 1。距离从某个整数开始，每次减 1，必然减到 0——这就"相遇"了。

### 要求

1. 先想：用一个 `HashSet` 存访问过的节点，遇到重复就说明有环。**写出这版**（O(n) 空间），跑通。
2. 再写快慢指针版（O(1) 空间）：`slow` 走一步，`fast` 走两步。
3. 循环条件要能处理空链表和单节点。
4. 自己构造带环的链表测试：尾节点指回第 k 个节点。

### 参考框架（只给签名，不给实现）

```java

    public boolean hasCycle(ListNode head) {
        // 你的代码
    }
}
```

### 验收

- [ ] 空链表 `null` 返回 false 不报 NPE
- [ ] 单节点无环返回 false
- [ ] `[3,2,0,-4]` 尾连到下标 1，返回 true
- [ ] `[1,2]` 尾连到下标 0，返回 true
- [ ] 无环的 10000 个节点，返回 false 且不超时
- [ ] 能口述"为什么快慢指针一定会相遇"

## 第二题：LeetCode 21 · 合并两个有序链表（简单）

### 题目

将两个升序链表合并为一个新的**升序**链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。

**示例 1：**

```
输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]
```

**示例 2：**

```
输入：l1 = [], l2 = []
输出：[]
```

**示例 3：**

```
输入：l1 = [], l2 = [0]
输出：[0]
```

**提示：**

- 两个链表的节点数目范围是 `[0, 50]`
- `-100 <= Node.val <= 100`
- `l1` 和 `l2` 均按**非递减顺序**排列

### 题眼

> 你手里有两叠已经排好序的扑克牌，每次从两叠的**顶部**比较，把小的那张放到新的一叠上。

关键：**`dummy` 节点**。你现在已经很熟了——有了假头，就不用特判"新链表的第一个节点是谁"。

### 要求

1. 用 `dummy` + `tail` 尾插，**不要新建节点**，直接复用原来的节点（把 `next` 指针改掉）。
2. 循环结束后，把**还没走完的那条链表整段接上**（不要用 `while` 一个个接，那是常见写法但慢）。
3. 写完后，用 `build` + `show` 测四组：`[1,2,4]+[1,3,4]`、`[]+[]`、`[]+[0]`、`[5]+[1,2,3]`。


### 验收

- [ ] 返回的链表是升序，且节点数 = 两条链表节点数之和
- [ ] 两个都为空返回 null（不是抛异常）
- [ ] 一条为空时，直接返回另一条（原样返回，不是复制）
- [ ] 四组用例全过

## 附：ListNode 模板（放进你自己的工具类里）

```java
class ListNode {
    int val;
    ListNode next;
    ListNode() { }
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }

    static ListNode build(int[] arr) {
        ListNode dummy = new ListNode(0);
        ListNode tail = dummy;
        for (int v : arr) {
            tail.next = new ListNode(v);
            tail = tail.next;
        }
        return dummy.next;
    }

    static String show(ListNode head) {
        StringBuilder sb = new StringBuilder("[");
        for (ListNode cur = head; cur != null; cur = cur.next) {
            sb.append(cur.val);
            if (cur.next != null) sb.append(",");
        }
        return sb.append("]").toString();
    }
}
```
