# 记账本（控制台版）

Java 学习第 1 周的练手项目：用控制台管理收支记录。

## 功能
- 添加一笔（日期、类型、金额、备注）
- 查看全部，显示合计收入/支出
- 按类型筛选
- 统计总收入、总支出、结余
- 删除最后一笔
- 按金额从大到小排序

## 运行环境
- JDK 17 及以上（我用的是 JDK 21）

## 怎么运行
​```bash
javac -encoding UTF-8 -d out src/Bookkeeping.java
java -cp out Bookkeeping
​```

## 用了哪些知识
数组、方法、循环、switch、Scanner、printf 格式化、选择排序。

## 已知限制
- 数据不保存，退出即丢失（下一步要学文件 IO）
- 最多 100 笔
- 单文件实现，还没拆成类

## 学到的东西
- 四个平行数组要一起交换，容易错位 → 理解了"对象"为什么存在
- `count` ≠ `length`：前者是有效数据量，后者是容量
- 所有输入都要校验，否则 Scanner 一崩全崩
