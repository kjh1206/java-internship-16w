## 题一：239. 滑动窗口最大值（困难）

**链接**：https://leetcode.cn/problems/sliding-window-maximum/

### 题目

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回**滑动窗口中的最大值**。

**示例 1**

```
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]

解释：
滑动窗口的位置                最大值
---------------               -----
[1  3  -1] -3  5  3  6  7       3
 1 [3  -1  -3] 5  3  6  7       3
 1  3 [-1  -3  5] 3  6  7       5
 1  3  -1 [-3  5  3] 6  7       5
 1  3  -1  -3 [5  3  6] 7       6
 1  3  -1  -3  5 [3  6  7]      7
```

**示例 2**

```
输入：nums = [1], k = 1
输出：[1]
```

### 提示

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`
- `1 <= k <= nums.length`

### 题眼

- 暴力：每个窗口扫 k 个 → O(nk)，n=10^5 会超时
- **单调队列**：队列里存**下标**，对应的值**从队头到队尾单调递减**
- 三个动作：
  1. **出队**：如果队头下标已经滑出窗口（`<= i - k`），弹出队头
  2. **入队**：新元素进来时，把队尾所有**比它小或相等**的元素弹掉（它们永远不会成为最大值），再入队
  3. **取最大**：队头就是当前窗口最大值
- 每个下标进队一次、出队一次 → O(n)

模板：

```java
Deque<Integer> dq = new ArrayDeque<>();     // 存下标
int[] ans = new int[n - k + 1];
for (int i = 0; i < n; i++) {
    // ① 队头过期
    if (!dq.isEmpty() && dq.peekFirst() <= i - k) dq.pollFirst();
    // ② 队尾比当前小的全部弹掉
    while (!dq.isEmpty() && nums[dq.peekLast()] <= nums[i]) dq.pollLast();
    // ③ 入队
    dq.offerLast(i);
    // ④ 窗口形成后记录答案
    if (i >= k - 1) ans[i - k + 1] = nums[dq.peekFirst()];
}
```

**为什么是 `<=` 而不是 `<`**：值相等时保留旧的没意义（旧的会先过期），弹掉旧的更好。

### 要求

1. 用 `ArrayDeque` 存下标，实现上述四步
2. 自己补 6 组测试：示例 1~2、全相同 `[5,5,5,5]` k=2、递增 `[1,2,3,4]` k=2、递减 `[4,3,2,1]` k=2、窗口等于数组 `k=n`
3. 再写一个暴力版，用随机数组对比两者结果（这点很重要，单调队列的边界很容易写错）

### 验收

- [ ] 6 组测试全过
- [ ] 随机对比 1000 组与暴力版结果一致
- [ ] 能口述"为什么每个元素最多进出队一次，所以 O(n)"
- [ ] 能解释"为什么队列里存下标而不是值"（要判断是否滑出窗口）

## 题二：150. 逆波兰表达式求值（中等）

**链接**：https://leetcode.cn/problems/evaluate-reverse-polish-notation/

### 题目

给你一个字符串数组 `tokens`，表示一个根据**逆波兰表示法**（后缀表达式）表示的算术表达式。

请你计算该表达式。返回一个表示表达式值的整数。

**注意**：

- 有效的算符为 `'+'`、`'-'`、`'*'` 和 `'/'`。
- 每个操作数（运算对象）都可以是一个整数或者另一个表达式。
- 两个整数之间的除法总是**向零截断**。
- 表达式中不含除零运算。
- 输入是一个根据逆波兰表示法表示的算术表达式。
- 答案及所有中间计算结果可以用 **32 位**整数表示。

**示例 1**

```
输入：tokens = ["2","1","+","3","*"]
输出：9
解释：该算式转化为常见的中缀算术表达式为：((2 + 1) * 3) = 9
```

**示例 2**

```
输入：tokens = ["4","13","5","/","+"]
输出：6
解释：((4 + (13 / 5)) = 6
```

**示例 3**

```
输入：tokens = ["10","6","9","3","+","-11","*","/","*","17","+","5","+"]
输出：22
```

### 提示

- `1 <= tokens.length <= 10^4`
- `tokens[i]` 是一个算符（`"+"`、`"-"`、`"*"` 或 `"/"`），或是在范围 `[-200, 200]` 内的一个整数
- 逆波兰表达式总是有效的。换句话说，表达式总会得出有效数值且不存在除数为 0 的情况。

### 题眼

- 后缀表达式的求值规则极其简单：**遇到数字压栈，遇到运算符弹出两个数、算完再压回去**
- 关键顺序：**先弹出的是右操作数，后弹出的是左操作数**
  - `a - b`：`b = pop()`，`a = pop()`，结果是 `a - b`
  - `a / b`：同上，`a / b`（不是 `b / a`）
- 除法向零截断：Java 的 `int` 除法天然满足（`-7 / 2 == -3`），不需要特殊处理
- 最后栈里剩一个数，就是结果

模板：

```java
Deque<Integer> stack = new ArrayDeque<>();
for (String t : tokens) {
    switch (t) {
        case "+", "-", "*", "/" -> {
            int b = stack.pop();
            int a = stack.pop();
            stack.push(switch (t) {
                case "+" -> a + b;
                case "-" -> a - b;
                case "*" -> a * b;
                default  -> a / b;
            });
        }
        default -> stack.push(Integer.parseInt(t));
    }
}
return stack.pop();
```

### 要求

1. 用 `ArrayDeque` 当栈
2. 用 `switch` 表达式（JDK 14+ 的箭头语法），**不要写 if-else 链**
3. 注意 `-` 和 `/` 的操作数顺序（这是本题唯一的坑）
4. 自己补 5 组测试：示例 1~3、单数字 `["42"]`、含负数 `["-3","2","*"]`（结果 -6）

### 验收

- [ ] 5 组测试全过
- [ ] 能说出"为什么先弹出的是右操作数"
- [ ] 能回答：如果运算符是 `-` 而你写成了 `b - a`，示例 2 会输出什么？（0，而不是 6）
