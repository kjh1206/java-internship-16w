## 题一：相交链表（LeetCode 160）

**难度**：简单｜**标签**：链表、双指针、哈希表

### 题目描述

给你两个单链表的头节点 `headA` 和 `headB`，请你找出并返回两个单链表相交的起始节点。如果两个链表不存在相交节点，返回 `null`。

图示两个链表在节点 `c1` 开始相交：

```
A:  a1 → a2 ↘
              c1 → c2 → c3
B:  b1 → b2 → b3 ↗
```

题目数据保证整个链式结构中不存在环。注意，函数返回结果后，链表必须保持其原始结构。

**进阶**：你能否设计一个时间复杂度 `O(n)`、仅用 `O(1)` 内存的解决方案？

### 示例

```
输入：intersectVal = 8, listA = [4,1,8,4,5], listB = [5,6,1,8,4,5], skipA = 2, skipB = 3
输出：Intersected at '8'
解释：相交节点的值为 8。从各自的表头开始算起，链表 A 为 [4,1,8,4,5]，
     链表 B 为 [5,6,1,8,4,5]。（注意：如果两个链表相交，则从相交节点开始后面的节点都相同）

输入：intersectVal = 2, listA = [1,9,1,2,4], listB = [3,2,4], skipA = 3, skipB = 1
输出：Intersected at '2'

输入：intersectVal = 0, listA = [2,6,4], listB = [1,5], skipA = 3, skipB = 2
输出：null（不相交）
```

### 题眼（想不出来再看）

<details>
<summary>点开看提示</summary>

**思路一（好想，但要 O(n) 空间）**：先遍历 A，把每个节点放进 `HashSet`；再遍历 B，第一个"在集合里"的节点就是交点。

**思路二（O(1) 空间，面试要的是这个）**：两个指针 `pa`、`pb` 分别从各自头节点出发，每次各走一步，**走到 null 就换到另一条链表的头**继续走。

为什么对：设 A 独有部分长 `a`，B 独有部分长 `b`，公共部分长 `c`。

- `pa` 的路径：`a + c + b`
- `pb` 的路径：`b + c + a`

两者总长相等 → 走完这些步数，要么同时到达交点，要么同时变成 `null`（不相交）。

代码骨架：

```java
ListNode pa = headA, pb = headB;
while (pa != pb) {
    pa = (pa == null) ? headB : pa.next;
    pb = (pb == null) ? headA : pb.next;
}
return pa;   // 相交时是交点，不相交时是 null
```

注意：**判断 `pa == null` 是在"走之前"还是"走之后"**，决定了循环终止条件，写错会死循环。

</details>

### 要求

```java
public class Solution {
    public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
        // 你的代码
    }
}
```

- 时间 `O(n)`，空间 `O(1)`（用 `HashSet` 也能过，但要能写出双指针版）
- 写一个 `buildIntersect(int[] a, int[] b, int skipA, int skipB)` 构造相交链表用于测试

### 自测用例

| listA | listB | skipA | skipB | 期望 |
|---|---|---|---|---|
| `[4,1,8,4,5]` | `[5,6,1,8,4,5]` | 2 | 3 | 值为 8 的节点 |
| `[1,9,1,2,4]` | `[3,2,4]` | 3 | 1 | 值为 2 的节点 |
| `[2,6,4]` | `[1,5]` | 3 | 2 | `null` |
| `[]` | `[1]` | 0 | 1 | `null` |

### 验收

- [ ] 4 组用例全过
- [ ] 能口述"两条路径等长"的证明
- [ ] 代码里没有 `HashSet`

## 题二：两两交换链表中的节点（LeetCode 24）

**难度**：中等｜**标签**：链表、递归、指针

### 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

### 示例

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]

输入：head = []
输出：[]

输入：head = [1]
输出：[1]

输入：head = [1,2,3]
输出：[2,1,3]     ← 奇数个节点，最后一个不动
```

### 题眼（想不出来再看）

<details>
<summary>点开看提示</summary>

**迭代版（推荐先写）**：

```
dummy → 1 → 2 → 3 → 4
        ↑   ↑
        a   b
```

每一轮处理 `dummy/prev` 后面的两个节点 `a`、`b`：

```
prev.next = b;          // ① prev 指向 b（2）
a.next = b.next;        // ② 1 指向 3（a 跨过 b）
b.next = a;             // ③ 2 指向 1
prev = a;               // ④ prev 前进到 1，准备下一对
```

四步顺序不能乱，尤其 ① 必须在 ② 之前（否则 `b.next` 已经被改了）。

**递归版（写起来短，理解要求高）**：

```java
public ListNode swapPairs(ListNode head) {
    if (head == null || head.next == null) return head;
    ListNode second = head.next;
    head.next = swapPairs(second.next);   // 后面的先换好
    second.next = head;                   // 再换这一对
    return second;
}
```

递归的"宏观语义"：`swapPairs(x)` 返回"从 x 开始两两交换后的新头"。

</details>

### 要求

```java
public class Solution {
    public ListNode swapPairs(ListNode head) {
        // 迭代版
    }
}
```

- 至少写出**迭代版**；递归版作为加分
- 不许改 `val`（只能改 `next` 指向）

### 自测用例

| 输入 | 期望 |
|---|---|
| `[1,2,3,4]` | `[2,1,4,3]` |
| `[1]` | `[1]` |
| `[]` | `[]` |
| `[1,2,3]` | `[2,1,3]` |
| `[1,2]` | `[2,1]` |

### 验收

- [ ] 5 组用例全过
- [ ] 能说清"为什么 ① 必须在 ② 之前"
- [ ] 迭代版循环条件是 `prev.next != null && prev.next.next != null`
